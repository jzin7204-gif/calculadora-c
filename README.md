# 🧮 Calculadora em C

Projeto de uma calculadora simples desenvolvida em linguagem C.

##  Funcionalidades

* ➕ Soma
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* 🔢 Menu de opções
* ⚠️ Mensagem para operação inválida

##  Tecnologias utilizadas

* Linguagem C
* Visual Studio Code

##  Conceitos praticados

Neste projeto foram praticados conceitos básicos da linguagem C:

* `printf`
* `scanf`
* Variáveis
* `switch/case`
* Operações matemáticas
* `float`
* Estruturas condicionais

##  Como executar

É necessário ter um compilador C instalado.

### Compilar

```bash
gcc calculadora.c -o calculadora
```

### Executar no Windows

```bash
calculadora.exe
```

##  Objetivo

Este projeto foi desenvolvido com o objetivo de praticar os conceitos básicos de programação em C e utilizar o Git e GitHub para versionamento do código.
